# ObjectMessageDeliverer

**Purpose & Responsibilities**

`ObjectMessageDeliverer` is a lightweight visitor functor defined in `GridNotifiers.h` within the `MaNGOS` namespace. Its sole responsibility is to deliver a specific `WorldPacket` to all client cameras (representing connected players) currently registered in a grid cell's `CameraMapType`.

It implements the Visitor pattern used by the MaNGOS grid system to iterate over objects in a spatial partition. Unlike other deliverers in this header that filter by distance, team, or sender identity, `ObjectMessageDeliverer` performs an unfiltered broadcast to every camera in the visited grid cell. It is typically used when a message originates from a non-player `WorldObject` (such as a `Creature`, `GameObject`, or `Corpse`) and needs to be sent to all observers in that immediate area.
