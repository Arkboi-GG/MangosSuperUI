# MapID

## Purpose & Responsibilities

`MapID` is a lightweight, aggregate struct defined in `MapManager.h` that serves as the unique composite key for identifying specific map instances within the `wowvmangos` server architecture. In this game engine, a "map" is identified not just by its base content ID (e.g., the zone or dungeon type), but also by a specific instance number. This distinction is critical for handling instanced content (such as dungeons, raids, or battlegrounds) where multiple separate copies of the same logical map exist simultaneously, as well as for managing the different phased regions of the main continents.

The struct encapsulates two `uint32` values:
1.  **`nMapId`**: The base identifier for the map content (e.g., Elwynn Forest, Molten Core).
2.  **`nInstanceId`**: The specific instance number. For non-instanced maps (like the open world continents), this is typically `0`. For instanced content, this is a unique integer generated by the `MapManager` to distinguish between concurrent groups playing in the same dungeon.

`MapID` is primarily used as the key type for the `MapManager::MapMapType` (`std::map<MapID, Map*>`), allowing the server to efficiently look up, store, and manage pointers to `Map` objects. It provides standard comparison operators (`operator<` and `operator==`) to enable its use in sorted associative containers and equality checks.

## Member-by-Member Behavior

### Construction

**`MapID(uint32 id)`**
This constructor initializes a `MapID` with a specified map ID and defaults the instance ID to `0`. It is used when referring to non-instanced maps or when the instance context is irrelevant or default.

**`MapID(uint32 id, uint32 instid)`**
This constructor initializes both the map ID and the instance ID. It is the primary constructor used when creating or referencing specific instances of dungeons, battlegrounds, or phased continent regions.

### Comparison Operators

**`operator<(MapID const& val) const`**
Implements lexicographical comparison for sorting purposes. It first compares `nMapId`. If the map IDs are equal, it compares `nInstanceId`. This ordering ensures that all instances of a specific map are grouped together in sorted containers like `std::map`, with instance `0` (usually the default/non-instanced version) appearing before positive instance numbers. This logic is essential for the `MapManager::DoForAllMapsWithMapId` template function, which uses `lower_bound` to iterate over all instances of a specific map ID.

**`operator==(MapID const& val) const`**
Checks for strict equality between two `MapID` objects. Both `nMapId` and `nInstanceId` must match for the objects to be considered equal.

## Cross-Unit Boundaries

`MapID` itself contains no logic that calls out to other units. However, it is heavily integrated with `MapManager` (defined in `MapManager.h`/`MapManager.cpp`).

*   **Called by `MapManager`**:
    *   `MapManager::CreateMap`, `MapManager::CreateInstance`, `MapManager::CreateBattleGroundMap`, `MapManager::CreateTestMap`, `MapManager::DeleteInstance`, `MapManager::DeleteTestMap`, and `MapManager::FindMap` all construct `MapID` objects to index into the internal `i_maps` container.
    *   The `MapManager::DoForAllMapsWithMapId` template function constructs temporary `MapID` objects to define the range of iterators for iterating over all instances of a given map ID.

## Data Model

`MapID` does not interact directly with any database tables. It is an in-memory data structure used for runtime management of map objects. The persistence of instance data (which might include instance IDs) is handled by higher-level classes such as `InstanceSave` or `DungeonPersistentState`, which are not part of this unit.

## Notable Implementation Details

*   **Lexicographical Sorting**: The implementation of `operator<` prioritizes `nMapId` over `nInstanceId`. This is a deliberate design choice that allows efficient range-based queries. For example, finding all instances of map ID `X` involves finding the lower bound of `{X, 0}` and the lower bound of `{X+1, 0}`. This avoids iterating through the entire map container.
*   **Default Instance ID**: The single-argument constructor defaults `nInstanceId` to `0`. This aligns with the convention that non-instanced maps (continents) use instance ID `0`.
*   **Aggregate Structure**: `MapID` is a simple struct with public members. It does not hide its data, allowing direct access to `nMapId` and `nInstanceId` where necessary, though the constructors provide a cleaner interface for creation.

## Member Reference

**`MapID`**
Constructor that takes a single `uint32` argument for the map ID, initializing the instance ID to `0`. Used for non-instanced maps.

**`MapID#2`**
Constructor that takes two `uint32` arguments: the map ID and the instance ID. Used for creating specific instances of maps, including dungeons, battlegrounds, and phased continent regions. Called by various `MapManager` methods such as `CreateMap`, `CreateInstance`, `CreateBattleGroundMap`, `CreateTestMap`, `DeleteInstance`, `DeleteTestMap`, and `FindMap`.

**`operator<`**
Comparison operator that implements lexicographical ordering. First compares `nMapId`; if equal, compares `nInstanceId`. Enables use in sorted containers like `std::map` and supports range-based iteration in `MapManager::DoForAllMapsWithMapId`.

**`operator==`**
Equality operator that returns true if both `nMapId` and `nInstanceId` are equal to those of the compared `MapID` object.
