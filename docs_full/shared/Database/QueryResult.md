# QueryResult

`QueryResult` is the abstract base class defining the interface for iterating over database query results in `wowvmangos`. It decouples server logic from specific database drivers by providing a standard cursor-based API. The class holds no data buffers; it stores only metadata (`mRowCount`, `mFieldCount`) and a pointer to the current row (`mCurrentRow`), which is managed by derived implementations like `QueryResultMysql`.

A companion class, `QueryNamedResult`, is defined in the same header. It wraps a `QueryResult` to enable string-based field access (e.g., `result["id"]`) by mapping column names to indices, delegating all iteration and data retrieval to the underlying `QueryResult`.

## Purpose & Responsibilities

1.  **Abstraction:** Provides a uniform way to read query results regardless of the underlying database engine.
2.  **Iteration:** Manages the cursor state via `NextRow()`, allowing sequential processing of rows.
3.  **Access:** Exposes current row data via `Fetch()` (pointer to `Field` array) and `operator[]` (indexed `Field` reference).
4.  **Metadata:** Stores and reports the total row and field counts determined by the database driver.

## Member-by-Member Behavior

### Construction and Destruction

**`QueryResult` (Constructor)**
Initializes the result object with `rowCount` and `fieldCount` provided by the derived class. Sets `mCurrentRow` to `nullptr`, indicating no active row.

**`~QueryResult` (Destructor)**
Virtual destructor ensuring proper cleanup of derived class resources. Contains no custom logic.

### Iteration and Data Access

**`NextRow`**
Pure virtual method advancing the cursor to the next row. Returns `true` if a valid row is loaded, `false` if the result set is exhausted. Derived classes implement the actual buffer movement.

**`Fetch`**
Returns `mCurrentRow`, a pointer to the `Field` array of the current row. Returns `nullptr` if no row is selected. Callers must ensure `NextRow()` succeeded before using the result.

**`operator[]`**
Returns a constant reference to the `Field` at `index` in the current row. Assumes `mCurrentRow` is valid; dereferencing a null pointer causes undefined behavior if called before a successful `NextRow()`.

### Metadata Queries

**`GetFieldCount`**
Returns `mFieldCount`, the number of columns in the result set.

**`GetRowCount`**
Returns `mRowCount`, the total number of rows in the result set.

## Cross-Unit Boundaries

`QueryResult` is a passive interface; it calls no other units. It is extensively called by nearly every subsystem that loads data from the database:

*   **Initialization:** `ObjectMgr` uses it to load static world data (creatures, items, spells) at startup.
*   **Runtime Data:** `Player.Main` loads character state (inventory, skills) on login. `AccountMgr` handles authentication and ban lists.
*   **Commands:** `ChatHandler` variants use it to generate lists for GM commands (e.g., listing players or creatures).

Data flows from the database driver (via derived classes) into the caller. The caller iterates via `NextRow()` and extracts values via `operator[]` or `Fetch()`.

## Data Model

`QueryResult` is table-agnostic. It does not define or touch any specific database tables. The tables accessed depend entirely on the SQL query executed by the caller (e.g., `account`, `creature_template`, `character`).

## Notable Implementation Details

*   **Abstract Interface:** Cannot be instantiated directly. All instances are created by derived classes (e.g., `QueryResultMysql`).
*   **No Null Checks:** `Fetch()` and `operator[]` do not check if `mCurrentRow` is null. It is the caller's responsibility to verify `NextRow()` returned `true`.
*   **Non-Owning Pointer:** `mCurrentRow` points to memory owned by the derived class. The `QueryResult` object must remain alive while the row data is accessed.
*   **`QueryNamedResult` Overhead:** The wrapper performs a linear search for field names on every access, trading performance for code clarity.

## Member Reference

**QueryResult**
Constructor initializing row/field counts and setting the current row pointer to null.

**~QueryResult**
Virtual destructor for safe deletion through base pointers.

**NextRow**
Pure virtual method to advance the cursor; returns true if a row is available.

**Fetch**
Returns a pointer to the current row's `Field` array.

**operator[]**
Returns a reference to the `Field` at the given index in the current row.

**GetFieldCount**
Returns the number of columns in the result set.

**GetRowCount**
Returns the total number of rows in the result set.
