# Field

**Field** is a lightweight, non-owning wrapper for a single database column value. It stores a `char const*` pointer to a string buffer managed by the underlying database driver (`QueryResultMysql`) and a `DataTypes` tag. It provides zero-allocation access to query results by interpreting the raw C-string as specific C++ types, returning safe defaults for SQL `NULL` values.

## Purpose & Responsibilities

*   **Type Conversion:** Converts raw database strings to C++ primitives (`uint32`, `float`, `bool`, etc.) using standard library functions (`atol`, `atof`, `sscanf`).
*   **NULL Safety:** Returns default values (`0`, `0.0f`, `false`, `""`) if the underlying pointer is `nullptr`, preventing crashes on nullable columns.
*   **Memory Efficiency:** Avoids heap allocation. `GetString()` returns the raw pointer; `GetCppString()` creates a temporary `std::string` only when explicitly requested.

## Member-by-Member Behavior

### Construction & Destruction
*   **Field()**: Initializes `mValue` to `nullptr` and `mType` to `DB_TYPE_UNKNOWN`.
*   **Field(char const*, DataTypes)**: Sets `mValue` and `mType` from arguments. Used by `QueryResultMysql` to populate fields.
*   **~Field()**: Empty destructor; no memory management required.

### Data Access
*   **GetType()**: Returns the `DataTypes` enum.
*   **IsNULL()**: Returns `true` if `mValue` is `nullptr`.
*   **GetString()**: Returns the raw `char const*`. Valid only while the parent `QueryResult` is active.
*   **GetCppString()**: Returns a `std::string` copy, or `""` if NULL.
*   **GetFloat()**: Parses via `atof`; returns `0.0f` if NULL.
*   **GetBool()**: Parses via `atoi`; returns `true` if value > 0, else `false`. Returns `false` if NULL.
*   **GetUInt8/GetInt16/GetUInt16/GetInt32/GetUInt32**: Parse via `atol` and cast to fixed-width types. Return `0` if NULL.
*   **GetInt64/GetUInt64**: Parse via `sscanf` with `SI64FMTD`/`UI64FMTD`. Return `0` if NULL or parse failure.

### State Mutation
*   **SetType()**: Updates `mType`. Called by `QueryResultMysql`.
*   **SetValue()**: Updates `mValue` pointer. Called by `QueryResultMysql::NextRow` to advance to the next row's data without copying.

## Cross-Unit Boundaries

*   **Calls Out:** None.
*   **Called By:**
    *   **QueryResultMysql**: Constructs `Field` objects, calls `SetType` and `SetValue` to bind data.
    *   **Domain Managers**: Virtually all managers (`AccountMgr`, `ObjectMgr`, `Player.Main`, `ChatHandler`, `AuthSocket`, etc.) call `Field` getters to extract data from query results. Data flows strictly from the database driver through `Field` to application logic.

## Data Model

`Field` is table-agnostic. It operates on result sets from any table (e.g., `account`, `characters`, `creature_template`) depending on the caller's query.

## Notable Implementation Details

*   **Non-Owning Pointers:** `mValue` points to external memory. Storing `Field` objects or raw pointers beyond the current row's scope causes dangling references. Use `GetCppString()` for persistence.
*   **Copy Prevention:** Copy constructor and assignment operator are private and undefined, preventing accidental shallow copies.
*   **Parsing Limits:** Integer getters use `atol`, which may silently overflow for values exceeding 32-bit ranges. 64-bit getters use `sscanf` for robustness.
