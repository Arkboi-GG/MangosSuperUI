# Errors

The `Errors` unit provides runtime assertion handling and stack trace generation for the MaNGOS server. It defines the `MANGOS_ASSERT` macro for invariant checking and functions to dump call stacks to the log. It relies on the optional `cpptrace` library for symbol resolution; if disabled at compile time, it logs a warning instead of generating traces. It does not interact with any database tables.

## Purpose & Responsibilities

1.  **Assertion Handling:** The `MANGOS_ASSERT` macro checks conditions at runtime. On failure, it invokes `PrintStacktraceAndThrow` to log context (file, line, function, expression) and terminate execution.
2.  **Stack Trace Generation:** `PrintStacktrace` captures the current call stack, resolves symbols (function names, files, lines) via `cpptrace` if available, and logs them.
3.  **Diagnostic Feedback:** Warns if debug symbols are missing, preventing meaningful trace output.

## Member-by-Member Behavior

### Stack Trace Printing

**`PrintStacktrace`** (overloads)
Captures and logs the current execution stack.
*   The parameterless overload delegates to the two-parameter version with `skipFrames=1` and `maxFrames=64`.
*   The two-parameter overload:
    *   If `ENABLE_CPPTRACE` is undefined, logs a minimal message instructing users to enable it in CMake.
    *   If enabled, uses `cpptrace::generate_trace` to capture frames. It iterates through frames, logging index, address, symbol, filename, and line number (if available).
    *   If no frame contains both a line number and a non-empty symbol, it logs an error: suggesting PDB placement on Windows or rebuilding with debug symbols elsewhere.

### Assertion Failure Handling

**`PrintStacktraceAndThrow`**
Terminal handler for assertion failures, marked `[[noreturn]]`.
1.  Logs an error with filename, line, function, failed expression, and optional message.
2.  Calls `PrintStacktrace(1, 32)` to dump the top 32 frames.
3.  Throws `std::runtime_error` with the failure details.
4.  Executes `assert(false)` as a fallback if the exception is caught, ensuring termination.

## Cross-Unit Boundaries

### Calls Out

*   **`Log.Main/Out`**: Both `PrintStacktrace` and `PrintStacktraceAndThrow` use `sLog.Out` to write diagnostics. `PrintStacktrace` uses `LOG_LVL_MINIMAL` for frames and `LOG_LVL_ERROR` for missing symbol warnings. `PrintStacktraceAndThrow` uses `LOG_LVL_ERROR` for assertion details.

### Called By

*   **`PrintStacktraceAndThrow`**: Invoked indirectly via `MANGOS_ASSERT` from nearly all subsystems when invariants fail. Key callers include network layers (`AsyncSocket`, `AuthSocket`), game entities (`Player`, `Unit`, `Creature`), database interactions (`Database`, `SqlPreparedStatement`), movement/pathfinding (`MoveSpline`, `GridMap`), spells/combat (`Spell`, `ThreatManager`), and world management (`Map`, `MapManager`).
*   **`PrintStacktrace`**: Called manually by `Master/_OnSignal` (likely for signal handlers like SIGSEGV) and `Unit.Main/CleanupDeletedAuras` (for diagnosing aura cleanup issues).

## Notable Implementation Details

*   **Conditional Compilation:** `PrintStacktrace` functionality depends on `ENABLE_CPPTRACE`. If disabled, it acts as a no-op aside from logging a warning, reducing overhead but eliminating crash diagnostics.
*   **Symbol Heuristic:** Missing symbol detection checks if *any* frame has both a line number and non-empty symbol. If none do, it assumes symbols are missing entirely.
*   **Double-Fail Safety:** `PrintStacktraceAndThrow` throws `std::runtime_error` then asserts `false`. This ensures termination even if a global handler catches the exception, preventing undefined behavior propagation.
*   **Frame Skipping:** Both `PrintStacktrace` overloads skip frames (default 1, `PrintStacktraceAndThrow` skips 1) to exclude diagnostic function frames from the output.

## Member Reference

**PrintStacktrace**
Delegates to the two-parameter overload with `skipFrames=1` and `maxFrames=64`. Called by `Master/_OnSignal` and `Unit.Main/CleanupDeletedAuras`.

**PrintStacktrace#2**
Generates and logs a stack trace using `cpptrace` if enabled; otherwise logs a warning. Outputs frame details to `Log.Main/Out`. Warns if debug symbols are missing.

**PrintStacktraceAndThrow**
Logs assertion failure details, dumps a 32-frame stack trace via `PrintStacktrace`, throws `std::runtime_error`, and asserts `false` to ensure termination. Called by numerous units via `MANGOS_ASSERT`.
